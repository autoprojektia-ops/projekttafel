Desafio 01 · automação

Montar o cenário no Make (cerca de 20 minutos)

Uma automação só, ligada ao gargalo: quando o pedido fica “Apto para validação”, o coordenador recebe um e-mail. Conta gratuita do Make chega.

O que precisa estar aberto

  • Conta Google (Gmail + Planilhas).
  • Conta no make.com.
  • Os 3 CSV desta pasta.

A. Planilhas no Google Drive (caminho mais simples)

  1. Abra o ficheiro Guaras-Controle-de-mobilizacoes.xlsx desta pasta (já tem as 3 abas).
  2. Arraste-o para o Google Drive → clique com o botão direito → Abrir com → Planilhas Google.
  3. Confirme as abas: Mobilizacoes, Treinamentos, FilaCoordenador.
  4. Na aba FilaCoordenador deixe a linha do Rafael como histórico. O teste do vídeo usa uma linha nova.
  5. Compartilhar: qualquer pessoa com o link pode ver. Copie o link.

Os três ficheiros .csv são o mesmo conteúdo, um por aba — use só se preferir importar à mão.

A aba FilaCoordenador é a “versão visível” do passo 4 do algoritmo. Hoje o estado só muda na planilha geral e ninguém é avisado. No estado futuro, ao ficar Apto nasce uma linha nesta fila — e o Make dispara o e-mail.

B. Cenário no Make

  1. make.com → Create a new scenario.
  2. Nome (canto de cima): Aviso ao coordenador quando fica Apto.
  3. Clique no círculo grande → pesquise Google Sheets → Watch New Rows.
  4. Create a connection → entre com a mesma conta Google da planilha → permitir acesso.
  5. Spreadsheet: Guarás — Controle de mobilizações.
  6. Sheet: FilaCoordenador.
  7. Table contains headers: Yes.
  8. Limit: 1. Guarde o módulo (OK / Save).
  9. Clique na bolinha à direita do módulo Sheets → Add a filter.
  10. Label: Só Apto para validação.
  11. Condition: campo Status → Equal to → texto Apto para validação. Exato, com acento.
  12. À direita do filtro → adicione Gmail → Send an Email.
  13. Connection: a mesma conta Google.
  14. To: o seu Gmail (no vídeo você é o coordenador e mostra a caixa de entrada).
  15. Subject (copie):

Apto para validação: {{Nome}} — {{ObraDestino}}

Clique em Nome e ObraDestino nos campos que o Make mostrou do Sheets. Não digite as chaves à mão se o painel oferecer o item.

Content (copie e mapeie os campos iguais):

A solicitação ficou pronta para a sua validação.

Nome: {{Nome}}
Matrícula: {{Matricula}}
Função: {{Funcao}}
Obra: {{ObraDestino}}
Estado: {{Status}}

Treinamentos:
- {{Treinamento1}}: {{T1}}
- {{Treinamento2}}: {{T2}}
- {{Treinamento3}}: {{T3}}

Pode validar sem abrir a planilha geral no horário de costume.
  1. Save no módulo Gmail.
  2. Save no cenário (disquete / Ctrl+S).

  4. Quando funcionar: Scheduling → On (a cada 15 min no plano grátis chega; no vídeo use sempre Run once).

Não faça no vídeo

Não mostre senha. Não ligue outros módulos. Não automatize contratação nem certificado. Uma linha nova na fila + um e-mail é a prova do gargalo.
