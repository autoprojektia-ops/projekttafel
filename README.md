# Automação Make — Mobilização Guarás

Projeto público de **automação no Make.com**: conferência de treinamentos e liberação de colaborador para obra (Desafio 01).

Não inclui projetos pessoais nem o quadro Lurvek — esses ficam só no computador.

## O que tem aqui

- Roteiro do cenário Make (`docs/desafio/roteiro-make.html` e `roteiro-make-visual.html`)
- Prints do fluxo Make (`docs/desafio/imagens-make/`)
- Estudo de caso e planilhas de apoio
- Fluxograma do processo

## Como ver

1. Abra a pasta `docs/desafio/`
2. Comece por `roteiro-make-visual.html` ou `README.md` dentro de `desafio`
